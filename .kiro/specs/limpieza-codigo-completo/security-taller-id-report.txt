HALLAZGO 1 — app/rutas/whatsapp_ruta.py — CRÍTICO
  Método: enviar_whatsapp_mobile()
  Línea: ~80
  Código:
    resultado = await whatsapp_service.enviar_mensaje_manual(
        ticket_id, ticket.taller_id, telefono, body.mensaje, db
    )
  DESCRIPCIÓN: Se usa ticket.taller_id (del objeto de BD) en lugar del JWT.
  Aunque en este caso el ticket ya fue consultado de la BD, el problema es
  que no hay autenticación previa — cualquiera puede llamar este endpoint.
  Si hubiera autenticación, usar ticket.taller_id sería aceptable (es de BD,
  no del cliente), pero el patrón correcto sería verificar que
  ticket.taller_id == request.state.taller_id.
  SEVERIDAD: CRÍTICO (combinado con falta de autenticación)
