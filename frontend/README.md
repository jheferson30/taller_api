# Frontend Taller (Gris)

## Requisitos
- Node.js 18+

## Configuracion
Opcional, crea `.env`:

```bash
VITE_API_URL=http://127.0.0.1:8000
```

## Ejecutar

```bash
npm install
npm run dev
```

Abrir:
- `http://127.0.0.1:5173`

## Modulos
- Recepcion (`/`)
- Tickets (`/tickets`)
- Economia (`/economia`)
